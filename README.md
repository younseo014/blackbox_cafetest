# Blackbox Cafe Test

사장님용 메모리 가드 복제본입니다. 개발자 모드와 자체테스트 화면 없이 카메라 스켈레톤 인식, 촬영 종료 후 자동 업무 라벨링, 스켈레톤 좌표 내보내기를 제공합니다.

## 실행

Node.js 22.13 이상이 필요합니다.

```bash
npm ci
npm run prepare:actions
npm run dev
```

표시된 로컬 주소를 브라우저에서 열어 사용하세요. 데스크톱 앱은 `npm run build` 후 `npm start`로 실행합니다. 두 카메라의 동작 판별 시험은 `npm test`로 확인할 수 있습니다.

## 사용 흐름

1. 초기 설정에서 업종, 매장 구역, 업무 루틴을 등록합니다.
2. 홈의 **카메라 연결**을 눌러 접근을 허용합니다. 카메라 2대를 연결합니다. 두 화면에서 스켈레톤이 함께 인식되면 2시점으로 기록하고 분석합니다.
3. 스켈레톤 인식 상태를 확인하고 **촬영 마치고 자동 라벨링**을 누릅니다. 자동으로 확정하기 어려운 업무는 검토 목록에 남습니다.
4. 홈의 **스켈레톤 데이터 내보내기** 또는 **내 데이터 관리**에서 기록을 내려받습니다.

영상과 음성은 저장하지 않습니다. 좌표와 업무 기록은 이 앱의 로컬 저장소에 보관됩니다. 데스크톱 앱은 원본과 다른 앱 식별자와 주소를 사용해 저장소가 분리됩니다.

## 모델 파일

자동 라벨링에 쓰는 로컬 영상 모델과 ONNX 실행 파일은 저장소에 포함하지 않습니다. `npm run prepare:actions`가 고정된 모델 버전을 내려받고 SHA-256을 확인합니다. 인터넷 연결이 필요합니다. 사람 감지용 YOLOX 모델 파일도 저장소에 포함되지 않으며, 없으면 앱이 번들된 EfficientDet 모델을 사용합니다.
